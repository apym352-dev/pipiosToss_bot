# ⚔️ 토스 암살자 (Toss Assassin aVWAP) 시스템 공식 매뉴얼 v32.0

## 📌 1. 시스템 개요: 추세추종의 끝판왕 '토스 암살자'

🔹 **시스템 정체성**: '토스 암살자'는 미국 증시의 대표 3배 레버리지 반도체 인버스 ETF인 **SOXS(Bear)** 단일 종목만을 전담 요격하는 초정밀 aVWAP(세션 누적 거래량 가중 평균 가격) 순수 돌파/추종 무인 자동매매 퀀트 머신입니다. (SOXL 등 타 종목 전면 차단)  
🔹 **설계 철학**: 인간의 공포와 탐욕, 모니터링 피로도를 전면 배제합니다. 수학적으로 입증된 당일 세션 기관 수급선(VWAP)을 기준으로 04:01 정각 틱 다수결 분기망을 통해 덫을 장전하거나 요격하며, 보유 즉시 사용자 설정 수익률 기반 익절 덫(일반 지정가)을 서버에 심어놓고 퇴근하는 '원샷 원킬' 제로-오버나이트(Zero-Overnight) 방어형 시스템입니다.  
🔹 **하이브리드 요격망**: 봇 자체의 알고리즘에 의한 자동 매수뿐만 아니라, 운용자가 시장 기회를 포착하여 수동으로 매수한 물량까지 1.5초 이내에 원자적으로 감지하여 즉각 동적 익절 덫을 씌워 완벽 통제합니다.

## 🏛️ 2. 핵심 퀀트 매매 알고리즘 (순수 돌파/추종)

### 💡 세션별 독립 aVWAP 동적 연산
🔸 전일 종가의 영향을 100% 배제하고, SOXS 당일의 순수 거래대금 및 거래량을 기반으로 aVWAP을 세션별로 분리하여 독립 추적합니다.

### 💡 04:01 틱 다수결 분기망 및 휩소(Whipsaw) 바이패스
🔸 **04:00~04:01 EST 틱 수집**: 프리장 개장 직후 1분간 발생하는 실시간 틱(현재가)과 VWAP 데이터를 누적 수집하여 다수결(상회 vs 하회 틱 개수)을 연산합니다.  
🔸 **04:01 EST 정각 분기 타격**:  
  ▫️ **[VWAP 상회 틱 다수]**: 해당 시점의 VWAP 가격으로 즉시 지정가(LIMIT) 매수 덫을 장전합니다.  
  ▫️ **[VWAP 하회 틱 다수]**: 더 유리한 현재가(04:01:00 시가)로 지정가 요격을 발사합니다. 단, 순간적인 휩소로 시가가 VWAP보다 높게 튀어 오른 경우 타격을 대기(바이패스)하고, 다시 VWAP 아래로 회귀하는 원자적 순간에 현재가 타격을 격발합니다.  
🔸 **무한 대기 락온**: 발사된 모든 매수 주문(현재가 타격 및 VWAP 덫)은 거친 휩소 파동에 체결될 수 있도록 프리장 종료 시점(09:29 EST)까지 어떠한 경우에도 취소되지 않고 무한 대기합니다.

### 💡 NQ=F 매크로 3단 방어망 (대세장 이탈 방어)
🔸 **1차 방어 (진입 원천 차단)**: 매수 요격 직전 NQ=F 실시간 진폭이 2.0% 이상일 경우, 대세장 이탈로 간주하여 진입을 즉각 차단하고 당일 매수 권한을 100% 영구 소각합니다.  
🔸 **2차 방어 (절대 진폭 2.0% 덤핑)**: 진입 이후 당일 NQ=F 전체 진폭이 2.0%를 돌파하는 순간, 토스증권 팩트 평단가 대비 손실권(PnL < 0)이라면 기장전된 덫을 파기하고 전량 시장가(매수 1호가 스윕)로 덤핑 방어합니다.  
🔸 **3차 방어 (진폭 50% 동적 덤핑)**: 봇 진입 시점의 NQ=F 지수 및 진폭을 장부에 영구 기록합니다. 이후 지수가 진입 진폭의 50% 이상 변동했을 때 손실권(PnL < 0)이라면 대세 판별 실패로 규정, 즉시 전량 시장가 덤핑을 격발합니다.

## 🎯 3. 기계적 동적 타점 익절 시스템 (Dynamic Take-Profit Engine)

암살자의 익절 덫은 조건주문을 전면 배제하고, 가장 확실한 토스증권 일반 지정가(LIMIT) API로 직접 통제됩니다.

### ⚔️ 사용자 선택형 익절 덫 (팩트 평단가 락온)
🔸 텔레그램 제어반을 통해 사용자가 직접 설정한 목표 수익률(예: +0.5% 또는 +1.0%)을 기반으로 익절 타점을 동적 연산합니다.  
🔸 매수 체결 및 잔고 발생이 확인되는 즉시, 토스증권 원장의 팩트 평단가(averagePurchasePrice) 기준으로 산출된 지정가(LIMIT) 매도 주문을 전체 보유 물량에 대해 당일 유효(DAY) 조건으로 발사합니다.

### ⚔️ 수동 매수 개입 원자적 식별 (Manual Entry Mutex)
🔸 사용자가 봇 가동 중 수동으로 개입하여 잔고가 발생한 상황을 1.5초 이내에 원자적으로 식별합니다.  
🔸 포착 즉시 설정된 수익률 기반의 익절 덫을 강제 장전하며, 당일 봇의 자동 신규 진입 권한을 영구 소각하여 로직 충돌을 완벽히 방어합니다.

## ⏱️ 4. 운영 타임라인 및 4대 세션 스케줄

시스템의 모든 시계열은 100% 미국 동부 표준시(ZoneInfo('America/New_York'))로 통제됩니다.

🔹 **19:00 ~ 03:59 EST (🌙 시스템 대기 / Day Market)**  
🔸 무의미한 API Rate Limit 소진을 방어하기 위해 캔들 조회 및 VWAP 연산을 전면 셧다운하는 수면 상태입니다.  
🔹 **04:00 ~ 09:29 EST (🌅 1세션: 프리마켓 - 유일한 진입 창구)**  
🔸 04:00: 누적 캔들 0점 초기화 및 순수 프리장 aVWAP 연산 개시 (1분간 틱 수집 대기).  
🔸 04:01: 틱 다수결 분기망 격발 및 지정가 덫/요격 락온 (09:29까지 무한 대기 유지).  
🔹 **09:30 ~ 15:58 EST (🔥 2세션: 정규장 - 청산 전용 모드)**  
🔸 09:30: 정규장 aVWAP 독립 추적 개시. 프리장 미체결 덫은 전면 파기되며 당일 신규 매수 진입은 예외 없이 영구 소각됩니다.  
🔹 **15:59 ~ 16:01 EST (🛑 MOC 컷오프 - 제로 오버나이트 강제 청산)**  
🔸 봇이 [🟢 ON] 상태라면 어떠한 미체결 포지션도 밤을 넘길 수 없습니다.  
🔸 정규장 마감 1분 전(15:59), 기장전된 익절 덫을 선취소합니다.  
🔸 1.5초 간격으로 미체결을 스캔하여, 매수 1호가(Bid Price) 스윕을 통한 일반 지정가 매도를 융단폭격하여 손익 불문 전량 강제 청산합니다.  
🔹 **17:00 EST (🧹 자정 정산 및 전역 가비지 컬렉션)**  
🔸 인메모리 락 해제, 멱등성 키 소각 및 로컬 장부 자정 초기화를 실행합니다.

```
## ⚠️ 6. 운용자 절대 주의사항 (오버나이트 통제 철칙)

```

🚨 **봇 가동 중 오버나이트 불가 (Zero-Overnight 철칙)**
🔹 암살자는 100% 데이 트레이딩 머신입니다. 통합 제어반(`/settlement`)에서 봇이 [🟢 ON] 상태로 방치되어 있다면, 15:59 EST에 예외 없이 기계적 MOC 융단폭격 청산이 격발됩니다.

🚨 **수동 오버나이트 통제 (Bot OFF)**
🔹 포지션을 청산하지 않고 익일로 홀딩하고 싶다면, 반드시 15:59 EST 이전에 `/settlement` 메뉴에서 전술 가동 스위치를 [🔴 OFF]로 변경하십시오.  
🔹 봇 가동이 정지되면 MOC 강제 덤핑 루프가 완전히 셧다운되며, 기장전된 당일 유효(DAY) 매도 주문은 봇에 의해 안전 파기되거나 장 마감 시 자연 만료되어 수동 오버나이트 상태로 전환됩니다.  
🔹 봇 OFF 상태에서 수동으로 전량 매도하여 잔고가 0주가 될 경우, 봇은 이를 '수동 오버나이트(가동 OFF) 전환 및 수동 청산'으로 완벽히 식별하여 허위 익절 알림을 차단합니다.

## 🥷 7. 팩트 기반 지정가(LIMIT) 익절 덫 확인 방법

🔹 봇이 발사하는 익절 덫은 불안정한 조건주문(Conditional Order) API를 전면 배제하고, 토스증권의 가장 빠르고 확실한 **일반 주문 API (지정가 LIMIT, 당일 유효 DAY)** 를 사용합니다.  
🔹 봇이 매수를 완료하고 지정가 익절 덫을 장전한 내역은 토스증권 앱의 **[주식 주문 관리] ➡️ [일반 미체결]** 탭에서 실시간으로 확인할 수 있습니다. 호가창에도 즉시 노출되어 가장 높은 체결 우선순위를 보장받습니다.
